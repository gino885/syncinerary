# September 2026: a trip taking shape

Audience: friends collecting real recommendations and turning them into a shared
trip. Home opens or creates a trip. Setup gathers the minimum needed to search.
The itinerary lets the traveler focus on one day without losing the whole trip.

Tokens: mist canvas #F3F5F7 / #16181C, white surface #FFFFFF / #242832,
indigo ink #1D2B4F / #E9E7DF, muted slate #55586A / #94968F, existing vermilion
action #B93A22 / #E85A3F. System rounded semibold display, system body, monospaced
digits for dates and progress. Preserve existing semantic approval colors.

Home: an open, left-aligned invitation above a scrolling departure list and a
fixed safe-area action. Setup: three connected stops (destination, travelers,
daily rhythm), one visible form at a time, retaining values on back navigation.
Itinerary: a persistent date strip with a moving underline and a focused day,
plus an all-days view. No invented map geometry: the API currently has no stop
coordinates, and existing Google Maps directions remain the real route entry.

Signature: the same connected-stop language in setup progress and day navigation.
Spring motion signals advancing or selecting, press feedback is brief, and
Reduce Motion uses fades without spatial movement. Controls remain 44pt or more.

Critique: avoid copying the reference's generic chatbot orb, gradient slogan,
and pill-shaped everything. Replace the old heavy double-border primary button
on these screens with one quiet solid action. Keep asymmetry and useful whitespace,
but allow vertical scrolling at large text sizes. Remove decorative progress
labels and retain only the actual step count, title, and usable back action.

## Implemented and checked

Traditional Chinese Instagram and TikTok queries now use Traditional Chinese
travel vocabulary, including broadened searches; RedNote retains its Simplified
Chinese queries. The existing creator-locale flow remains the source of language.
Chinese queries improve targeting but cannot guarantee the language of every
provider result. Existing saved content is not regenerated by this UI change.

Home now scrolls and keeps creation/join actions in a safe-area footer. Setup
has three animated steps with preserved fields on back navigation. Itinerary
dates filter the visible day, retain an all-days view, and animate selection.
Stop and meal rows stack at accessibility sizes to avoid wrapping time columns.
New motion respects Reduce Motion; the previous-card action now does too.

Validation: 744 backend tests passed, Swift API contract tests passed, Ruff and
diff whitespace checks passed, and the final iOS simulator build succeeded.
Chinese simulator review covered home, city search/selection, all three setup
steps, preserved traveler input after Back, and a real saved itinerary filtered
to October 11. Light/dark and accessibility-size screenshots exposed and led to
fixes for setup progress wrapping and timeline time-column wrapping.

Screenshots are in the ignored `.data/ui-review` directory. No new discovery
run was started during UI testing. The local UI-review account and one city
autocomplete request were used; existing trip data was only read.

The reference's embedded map is not implemented: the current itinerary API
does not expose stop coordinates. Existing real Google Maps directions links
remain available. Full video analysis remains a separate research prototype.
