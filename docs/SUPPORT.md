# Syncinerary Support

For help with account access, trip planning, privacy choices, or deletion,
open a support request at:

https://github.com/gino885/syncinerary/issues

Do not include passwords, verification codes, session tokens, Anthropic API
keys, or private trip details in a public issue. Describe the screen and the
general problem only. For a security-sensitive report, ask for a private
contact channel without including the secret itself.

## Before requesting help

1. Confirm the iPhone is online and the app is current.
2. Retry the action once.
3. For AI planning, confirm every trip member has allowed Anthropic sharing
   under Account, AI privacy, and that the trip creator has an active
   Anthropic API key.
4. Include the app version, iOS version, and the exact error message.

Account deletion is available directly inside the app under Account, Delete
account. It does not require contacting support.
