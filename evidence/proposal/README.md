# English prototype screenshots

These screenshots were captured on September 15, 2026, from an isolated iOS
simulator preview build. The screens use English UI text and simulated demo
responses. They show the current interface design and flow, not a completed
research evaluation or independently verified place records.

- `preparation-room-en.png`: group trip setup, traveler preferences, and a
  shared social link before discovery begins.
- `gather-progress-en.png`: the asynchronous place-gathering progress screen
  during the checking-places phase.

The corresponding application code is in
`ios/Syncinerary/Features/Group/PreparationView.swift` and
`ios/Syncinerary/Features/Gathering/GatheringView.swift`.
